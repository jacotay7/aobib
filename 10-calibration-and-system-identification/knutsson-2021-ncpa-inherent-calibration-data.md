# Correction of static and non-common path aberrations in an adaptive optics system using inherent calibration data

**Knutsson et al. (2021)** · *Optics Express 29, 3406* · [Free full text](https://doi.org/10.1364/OE.408954) · DOI: [10.1364/OE.408954](https://doi.org/10.1364/OE.408954)

## Summary

Presents a focal-plane method for correcting system and non-common path aberrations in low-order AO systems. The method maximises a figure of merit equal to the integrated, non-normalised, tip-tilt-free optical transfer function of the science image. The optimisation uses the singular-value-decomposition modes already contained in the system's interaction matrix as the basis. The approach is reported to be stable and robust and to enable diffraction-limited imaging in an experimental setup for ophthalmic applications.

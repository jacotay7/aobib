# POPPY: Physical Optics Propagation in Python

**Perrin et al. (2012)** · *Software (Python); described in Proc. SPIE 8442* · [Free full text](https://poppy-optics.readthedocs.io/) · DOI: [10.1117/12.925230](https://doi.org/10.1117/12.925230)

## Summary

POPPY is an open-source Python package for physical optics propagation, developed at STScI as the optical engine of the WebbPSF simulator for JWST. Optical systems are described as series of planes with extensible element classes (stops, masks, lenses, aberrations), and wavefronts are propagated between planes with Fraunhofer or Fresnel approximations to compute monochromatic and polychromatic PSFs. It does not implement full Rayleigh-Sommerfeld or vector propagation. The reference paper (Perrin et al. 2012, Proc. SPIE 8442) is not freely available; the link points to the documentation.

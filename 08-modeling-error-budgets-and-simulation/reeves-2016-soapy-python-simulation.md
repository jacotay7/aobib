# Soapy: an adaptive optics simulation written purely in Python for rapid concept development

**Reeves (2016)** · *Software (Python); described in Proc. SPIE 9909, 99097F* · [Free full text](https://soapy.readthedocs.io/en/latest/intro.html) · DOI: [10.1117/12.2232438](https://doi.org/10.1117/12.2232438)

## Summary

Soapy is a Monte-Carlo AO simulation code written entirely in Python, aimed at rapid development of new AO concepts and as a learning tool for newcomers to AO. Simulations can be run end-to-end from a configuration file via the command line, scripts or an included GUI, while each component (atmosphere, line of sight, wavefront sensors, deformable mirrors, laser guide stars, reconstructors, science camera) is a Python object that can be used separately. The descriptive paper (Proc. SPIE 9909, 2016) is not freely available; the link points to the documentation.

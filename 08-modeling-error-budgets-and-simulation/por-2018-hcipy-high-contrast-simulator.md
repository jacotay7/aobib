# High Contrast Imaging for Python (HCIPy): an open-source adaptive optics and coronagraph simulator

**Por et al. (2018)** · *Software (Python); described in Proc. SPIE 10703, 1070342* · [Free full text](https://docs.hcipy.org/) · DOI: [10.1117/12.2314407](https://doi.org/10.1117/12.2314407)

## Summary

HCIPy is an open-source, object-oriented Python framework for end-to-end simulation of high-contrast imaging instruments. It defines wavefronts and optical elements with Fraunhofer and Fresnel propagators, supports polarization through Jones calculus, models turbulence with infinitely long phase screens (including scintillation via Fresnel propagation between layers), and implements wavefront sensors such as Shack-Hartmann and pyramid and coronagraphs such as vortex, Lyot and APP. Combining AO and coronagraphy in one framework allows simulations with feedback from focal-plane wavefront sensors. The reference paper (Proc. SPIE 10703) is not freely available; the link points to the documentation.

# OOPAO: Object Oriented Python Adaptive Optics

**Héritier et al. (2023)** · *Proc. AO4ELT7 (Avignon, 2023)* · [Free full text](https://hal.science/hal-04402878) · DOI: [10.13009/AO4ELT7-2023-052](https://doi.org/10.13009/AO4ELT7-2023-052)

## Summary

OOPAO is an open-source Python end-to-end AO simulation package that carries the object-oriented design of the MATLAB toolbox OOMAO over to Python. The paper serves as a user manual: it describes the main classes (multi-layer atmosphere, telescope pupil, deformable mirror with Gaussian or user-defined influence functions, pyramid and Shack-Hartmann wavefront sensors, NGS and LGS sources) and how they are combined to build and run AO loops. The code was first developed for internal use and then released publicly on GitHub with tutorials.

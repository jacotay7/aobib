# PASSATA - Object oriented numerical simulation software for adaptive optics

**Agapito et al. (2016)** · *Proc. SPIE 9909* · [Free full text](https://arxiv.org/abs/1607.07624) · DOI: [10.1117/12.2233963](https://doi.org/10.1117/12.2233963)

## Summary

PASSATA (PyrAmid Simulator Software for Adaptive opTics Arcetri) is an IDL and CUDA object-oriented Monte-Carlo end-to-end AO simulation code developed at Arcetri Observatory, originally to evaluate the LBT FLAO pyramid-based single-conjugate system. The version described simulates single-conjugate, multi-conjugate and ground-layer AO with Shack-Hartmann and pyramid sensors, for 8 m to 40 m telescopes and for point-like or resolved sources at finite or infinite distance. The paper describes the architecture, recent developments, and example applications.

# AOtools: a Python package for adaptive optics modelling and analysis

**Townson et al. (2019)** · *Optics Express 27, 31316* · [Free full text](https://arxiv.org/abs/1910.04414) · DOI: [10.1364/OE.27.031316](https://doi.org/10.1364/OE.27.031316)

## Summary

AOtools is an open-source Python package of building blocks for AO users and researchers. Version 1.0 includes tools for pupil-plane analysis, focal-plane image and PSF analysis, wavefront sensor processing, atmospheric turbulence modeling and phase-screen generation, physical optics propagation, and conversion between AO and astronomical units. The project emphasizes ease of installation and use, with documentation, automated unit tests and distribution through the Python Package Index.

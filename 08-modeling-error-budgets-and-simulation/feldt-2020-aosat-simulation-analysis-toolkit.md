# The adaptive optics simulation analysis tool(kit) (AOSAT)

**Feldt et al. (2020)** · *Proc. SPIE 11448, 114483S* · [Free full text](https://arxiv.org/abs/2102.03068) · DOI: [10.1117/12.2561404](https://doi.org/10.1117/12.2561404)

## Summary

AOSAT is a Python package for analysing the output of single-conjugate AO simulations, usable stand-alone or integrated into a simulation environment. Given residual wavefront frames, the pupil mask and a setup file, its tearsheet function runs standard analyzers covering PSF properties and quality, residual tip-tilt, the effect of pupil fragmentation, static and dynamic residual aberration modes, expected high-contrast performance with and without coronagraphs, and residual wavefront power spectral density. It is intended to bridge simple simulation outputs and full instrument simulators.

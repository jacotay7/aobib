# Budget d'erreur en optique adaptative : Simulation numérique haute performance et modélisation dans la perspective des ELT

**Ferreira (2018)** · *PhD thesis (in French)* · [Free full text](https://theses.hal.science/tel-02127074) · DOI: [10.70675/5c1389c0zd8e1z4761z8cbaz47bc9382bfd7](https://doi.org/10.70675/5c1389c0zd8e1z4761z8cbaz47bc9382bfd7)

## Summary

This thesis (in French) addresses the identification of adaptive-optics error sources in the context of extremely large telescopes, where the size of the systems makes numerical simulation computationally demanding. It describes development work on the GPU-accelerated COMPASS simulation platform to reach ELT-scale end-to-end simulations. It then presents a numerical error-breakdown tool that extracts each wavefront error contributor from an end-to-end run, and uses it to build and validate analytical models of the residual error and its correlations, with PSF estimation as the target application.

# PROPER: an optical propagation library

**Krist (2007)** · *Software (IDL/MATLAB/Python); described in Proc. SPIE 6675* · [Free full text](https://proper-library.sourceforge.net/) · DOI: [10.1117/12.731179](https://doi.org/10.1117/12.731179)

## Summary

PROPER is an optical propagation library from JPL, available in IDL, MATLAB and Python, that models light propagation through an optical system with Fourier-transform-based Fresnel and angular spectrum methods, choosing near- or far-field propagators at each surface by tracking a Gaussian pilot beam. It provides routines to create complex apertures, aberrated wavefronts and deformable mirrors, and is used in particular for high-contrast coronagraph modeling. The reference paper (Krist 2007, Proc. SPIE 6675) is not freely available; the link points to the project site, which distributes the code and manual.

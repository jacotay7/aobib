# Characterization of the MUSE NFM PSF as a function of atmospheric conditions: TipTop calibration

**Congiu et al. (2026)** · *Proc. SPIE 14150, 1415069* · [Free full text](https://arxiv.org/abs/2608.04819) · DOI: [10.1117/12.3102860](https://doi.org/10.1117/12.3102860)

## Summary

Addresses the lack of an accurate PSF model in the exposure time calculator for the MUSE narrow-field mode, which uses GALACSI laser tomography AO on the VLT. A large set of archival standard-star observations is analysed to quantify how the NFM PSF varies with airmass, seeing, coherence time, wind speed and wavelength. This reference dataset is used to calibrate TIPTOP, the fast AO PSF prediction tool planned for the next release of the MUSE NFM ETC. The authors find that realistic PSFs require an additional static aberration term and an airmass-dependent tip-tilt jitter term; the calibration performs well above 7000 A, while shorter wavelengths still need corrections, likely for unmodelled chromatic aberrations.

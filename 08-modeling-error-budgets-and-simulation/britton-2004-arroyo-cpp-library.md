# Arroyo

**Britton (2004)** · *Proc. SPIE 5497* · [Free full text](https://authors.library.caltech.edu/records/srb05-p3b42) · DOI: [10.1117/12.552316](https://doi.org/10.1117/12.552316)

## Summary

Arroyo is an open-source, cross-platform C++ class library for modeling electromagnetic wave propagation through atmospheric turbulence and adaptive optics systems. The paper describes the functionality of the library, including time-domain turbulence realizations, wave propagation and models of AO components, and its motivation as a common, reusable code base for many simulation applications. Future plans for the project are also discussed.

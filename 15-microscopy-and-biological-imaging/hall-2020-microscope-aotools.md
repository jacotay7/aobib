# Microscope-AOtools: a generalised adaptive optics implementation

**Hall et al. (2020)** · *Optics Express 28, 28987* · [Free full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC8219375/) · DOI: [10.1364/OE.401117](https://doi.org/10.1364/OE.401117)

## Summary

Describes Microscope-AOtools, an open-source software package that implements the essential methods for setting up and using adaptive optics in microscopes. The motivation is that AO is not widely adopted in biological imaging partly because of the effort needed to set up and operate it, and new users often reimplement existing methods for their own hardware. The package is written in a generalised way so that it can use a range of adaptive elements, wavefront-sensing techniques and sensorless correction methods. It is designed to be extensible as new techniques appear.

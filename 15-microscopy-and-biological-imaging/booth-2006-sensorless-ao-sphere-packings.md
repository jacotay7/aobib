# Wave front sensor-less adaptive optics: a model-based approach using sphere packings

**Booth (2006)** · *Optics Express 14, 1339* · [Free full text](https://doi.org/10.1364/OE.14.001339) · DOI: [10.1364/OE.14.001339](https://doi.org/10.1364/OE.14.001339)

## Summary

Develops a model for wavefront-sensorless adaptive optics systems that correct aberrations by maximising a photodetector signal through control of an adaptive element. Representing aberrations with a small number of orthogonal modes such as Zernike polynomials, the paper links the search problem to the geometry of sphere packings and coverings. This framework is used to analyse and optimise direct-search and hill-climbing algorithms. An efficient scheme is derived that estimates N Zernike modes from N+1 intensity measurements using a direct maximisation calculation.

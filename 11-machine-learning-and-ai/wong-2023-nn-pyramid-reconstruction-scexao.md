# Nonlinear wave front reconstruction from a pyramid sensor using neural networks

**Wong et al. (2023)** · *PASP 135, 114501* · [Free full text](https://arxiv.org/abs/2311.02595) · DOI: [10.1088/1538-3873/acfdcb](https://doi.org/10.1088/1538-3873/acfdcb)

## Summary

Tests whether a dense neural network can replace the matrix-vector-multiply linear reconstructor of a pyramid wavefront sensor, using daytime data from the SCExAO instrument at Subaru. In a first experiment with wavefronts built from 14 Zernike modes at modulation radii of 25 to 100 mas, the network gives more precise reconstruction at all modulations, with the advantage growing where the sensor is nonlinear. A second experiment with atmosphere-like wavefronts, using the SCExAO real-time software as the baseline, confirms that the network outperforms the linear reconstructor.

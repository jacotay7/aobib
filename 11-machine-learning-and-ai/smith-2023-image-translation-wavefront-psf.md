# Image-to-image translation for wavefront and point spread function estimation

**Smith et al. (2023)** · *JATIS 9, 019001* · [Free full text](https://doi.org/10.1117/1.JATIS.9.1.019001) · DOI: [10.1117/1.JATIS.9.1.019001](https://doi.org/10.1117/1.JATIS.9.1.019001)

## Summary

Develops a phase-estimation approach for point spread function reconstruction in which a conditional adversarial neural network is trained to predict the residual phase from wavefront-sensor data of a closed-loop AO system. The retrieved residual phase is used to compute the PSF of the simulated instrument. A detailed end-to-end simulation study with the COMPASS tool under different turbulence conditions is presented. The authors report that, on Strehl ratio and halo distribution metrics, the method outperforms a model-based PSF reconstruction baseline, and note that it is not limited by modelling assumptions such as independence between error terms.

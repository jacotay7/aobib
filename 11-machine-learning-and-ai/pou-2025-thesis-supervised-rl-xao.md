# Supervised and reinforcement learning for extreme adaptive optics with application to exoplanet imaging

**Pou Mulet (2025)** · *PhD thesis (HAL tel-05556384)* · [Free full text](https://theses.hal.science/tel-05556384) · DOI: [10.70675/bc7c0246z0725z411fza55fzdba3c70e0615](https://doi.org/10.70675/bc7c0246z0725z411fza55fzdba3c70e0615)

## Summary

Doctoral thesis combining several deep-learning models in the AO loop, each targeting a specific error source. It covers a reinforcement-learning controller trained online to reduce temporal error, and supervised models trained offline to handle pyramid wavefront sensor non-linearity and noise, with analysis of the behaviour of each model and an application to exoplanet imaging. The second part addresses deployment: the COSMIC real-time framework is adapted to run neural networks, with inference and training optimized using TensorRT and reduced floating-point precision.

# Tempestas ex machina: A review of machine learning methods for wavefront control

**Fowler & Landman (2023)** · *Proc. SPIE 12680 (Techniques and Instrumentation for Detection of Exoplanets XI)* · [Free full text](https://arxiv.org/abs/2309.00730) · DOI: [10.1117/12.2676536](https://doi.org/10.1117/12.2676536)

## Summary

Review of machine learning approaches to adaptive optics wavefront control, written with next-generation high-contrast imaging systems in mind. The authors define machine learning in simple terms and note that many linear methods now labelled as machine learning (e.g. data-driven predictive filters) have been developed for wavefront control over roughly three decades. They describe the limitations of the standard integral controller with respect to temporal lag and vibrations, survey the most common machine learning methods applied to the control problem (linear data-driven predictors, neural-network predictors and reinforcement learning), and review the literature on each.

# CHARM - A Tip-Tilt Tertiary System for the Calar Alto 3.5m Telescope

**Glindemann et al. (1997)** · *PASP 109, 688* · [Free full text](https://articles.adsabs.harvard.edu/pdf/1997PASP..109..688G) · DOI: [10.1086/133933](https://doi.org/10.1086/133933)

## Summary

Describes CHARM, a tip-tilt tertiary mirror system for the Calar Alto 3.5-m telescope that corrects atmospheric image motion using either a visible CCD tip-tilt sensor or the infrared science camera. In the infrared mode, a small subarray of the detector is read out rapidly to measure image motion while the rest of the array integrates long exposures, which allows correction in obscured regions where only infrared guide stars are available. Image motion is typically reduced to below 0.03 arcsec rms at 2.2 microns. Astronomical results from several observing runs are presented; a companion paper (Glindemann 1997, PASP 109, 682) derives the design parameters used to evaluate the system.

# Modified Gaussian influence function of deformable mirror actuators

**Huang et al. (2008)** · *Optics Express 16, 108* · [Free full text](https://doi.org/10.1364/OE.16.000108) · DOI: [10.1364/OE.16.000108](https://doi.org/10.1364/OE.16.000108)

## Summary

Introduces a modified Gaussian model of deformable-mirror actuator influence functions, with separate corrections in the azimuthal and radial directions derived from the residual between measured influence functions and a standard Gaussian. Using a simplex search, the fitting capability of the modified function is compared with that of the Gaussian function on data measured with a Zygo interferometer. The modified function fits the measured data substantially better, which matters for analysing the fitting capability of a mirror in simulation.

# Deformable mirror model for open-loop adaptive optics using multivariate adaptive regression splines

**Guzmán et al. (2010)** · *Optics Express 18, 6492* · [Free full text](https://doi.org/10.1364/OE.18.006492) · DOI: [10.1364/OE.18.006492](https://doi.org/10.1364/OE.18.006492)

## Summary

Proposes modelling a deformable mirror for open-loop AO, where the wavefront is measured before reaching the mirror, with multivariate adaptive regression splines (MARS), a non-parametric regression technique. The model takes the desired wavefront correction as input and outputs the actuator voltages. Experiments with an electrostrictive deformable mirror gave positioning errors of about 1.2% rms of the peak-to-peak wavefront excursion. Because the method does not depend on the physical parameters of the device, the authors suggest it can be used with any type of deformable mirror.

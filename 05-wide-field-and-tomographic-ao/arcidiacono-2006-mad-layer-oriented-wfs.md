# Laboratory testing the layer oriented wavefront sensor for the multiconjugate adaptive optics demonstrator

**Arcidiacono et al. (2006)** · *Proc. SPIE 6272, 627227* · [Free full text](https://arxiv.org/abs/0912.0879) · DOI: [10.1117/12.671252](https://doi.org/10.1117/12.671252)

## Summary

The paper reports the laboratory tests for the preliminary acceptance of the layer-oriented wavefront sensor built for ESO's Multi-conjugate Adaptive optics Demonstrator (MAD). The sensor can use up to eight reference stars over a 2 arcmin field, each with a pyramid splitting its light into four beams. Two objectives conjugated to different altitudes produce co-added pupil images, so that each detector senses a given layer. The tests checked the layer-oriented capabilities and the ability to measure phase screens placed at different altitudes.

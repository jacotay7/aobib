# Ground-Layer Adaptive Optics with Multiple Laser Guide Stars

**Hart et al. (2008)** · *Proc. AMOS Technical Conference (Maui, 2008), E17* · [Free full text](https://home.ifa.hawaii.edu/users/baranec/publications/AMOS_2008.pdf)

## Summary

Reports the first closed-loop results from an adaptive optics system using multiple laser guide beacons, on the 6.5 m MMT. Five Rayleigh beacons are formed by 532 nm lasers, with the return integrated over 20–29 km by dynamically refocusing the telescope optics. A single Shack-Hartmann sensor with 60 subapertures across the pupil images all five beacons on one detector, using electronic shuttering as the range gate, and correction is applied with the MMT's deformable secondary mirror. Used to correct boundary-layer turbulence, the system gave 0.2 arcsec image quality at 1.2–2.5 μm, nearly uniform over a 2 arcmin field, shown on the globular cluster M13 and an open cluster. The full journal account of this work (Hart et al. 2010, Nature) is not free; this conference paper on a co-author's page covers the same first results.

# Analysis of isoplanatic high resolution stellar fields by the StarFinder code

**Diolaiti et al. (2000)** · *A&AS 147, 335* · [Free full text](https://arxiv.org/abs/astro-ph/0009177) · DOI: [10.1051/aas:2000305](https://doi.org/10.1051/aas:2000305)

## Summary

The paper describes StarFinder, a code for the deep analysis of stellar fields in Nyquist-sampled AO images with high or low Strehl ratio. The PSF is extracted directly from the image frame so as to include the actual instrumental response and atmospheric effects, and is then used to detect and fit stars for astrometry and photometry. The code is written in IDL as a self-contained widget application with visualization and analysis tools. The method and applications to AO data are presented; StarFinder has since been widely used for crowded-field AO analysis, including the Galactic Center.

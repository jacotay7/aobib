# Optimal correction of distortion for high-angular-resolution images: Application to GeMS data

**Bernard et al. (2018)** · *MNRAS 473, 2590* · [Free full text](https://arxiv.org/abs/1709.08567) · DOI: [10.1093/mnras/stx2517](https://doi.org/10.1093/mnras/stx2517)

## Summary

Variable optical distortions in MCAO data limit astrometric and photometric accuracy. The paper presents a distortion correction method that, starting from prior knowledge of the static distortion, estimates the dynamic distortions for each observation set and each frame. It follows an inverse-problem approach that generalizes earlier image re-centering work to arbitrary distortion modes, with a weighted least-squares formalism and a detailed error budget. The influence of number of frames, field density, noise and aliasing is studied, and the method is applied to GeMS observations.

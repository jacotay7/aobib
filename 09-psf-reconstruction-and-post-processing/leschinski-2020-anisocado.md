# AnisoCADO: a python package for analytically generating adaptive optics point spread functions for the Extremely Large Telescope

**Leschinski & Gendron (2020)** · *arXiv:2006.14572 (software description)* · [Free full text](https://arxiv.org/abs/2006.14572)

## Summary

AnisoCADO is a Python package that analytically generates SCAO point spread functions for the ELT. Users can set key atmospheric and observational parameters affecting PSF shape and Strehl ratio, including the turbulence profile, the guide-star position relative to the science field and differential pupil transmission. The package is used to produce field-dependent (anisoplanatic) PSFs for instrument simulations such as those of MICADO. Documentation is hosted on Read the Docs.

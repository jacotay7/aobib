# New algorithms for adaptive optics point-spread function reconstruction

**Gendron et al. (2006)** · *A&A 457, 359* · [Free full text](https://arxiv.org/abs/astro-ph/0606681) · DOI: [10.1051/0004-6361:20065135](https://doi.org/10.1051/0004-6361:20065135)

## Summary

The paper addresses the computational cost of the classical PSF reconstruction algorithm (Véran et al. 1997), which requires a set of U_ij functions whose number scales as the square of the number of mirror modes. Two alternative algorithms are proposed, both based on an eigen decomposition of the covariance matrix of the residual phase in the space of corrected modes. The first works in the basis where this covariance is diagonal, reducing the number of U_ij functions to the number of mirror modes. The second draws random phase screens with the same statistics as the residual covariance, removing the need for U_ij functions altogether. Simulations show that both approaches reconstruct the PSF accurately while reducing storage and computation time.

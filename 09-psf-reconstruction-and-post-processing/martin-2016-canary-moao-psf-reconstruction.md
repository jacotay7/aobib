# PSF reconstruction validated using on-sky CANARY data in MOAO mode

**Martin et al. (2016)** · *Proc. SPIE 9909, 99091Q* · [Free full text](https://arxiv.org/abs/1610.02176) · DOI: [10.1117/12.2231424](https://doi.org/10.1117/12.2231424)

## Summary

The paper presents a PSF reconstruction algorithm for multi-object adaptive optics that uses system telemetry and atmospheric tomography to estimate the PSF anywhere in the field, as needed for integral field spectroscopy with future MOAO spectrographs. The tomographic approach, using only off-axis wavefront sensor data, is compared with a reference approach based on the on-axis residual phase measured by a truth sensor. More than 450 on-sky CANARY PSFs were reconstructed. The tomographic method yields H-band Strehl bias/standard deviation of 1.3/4.8 points with 92.3% correlation to sky values, compared with 0.4/3.5 and 95% for the reference method; FWHM results are also reported.

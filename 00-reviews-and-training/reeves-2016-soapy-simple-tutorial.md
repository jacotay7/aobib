# Soapy simple tutorial (Python AO simulation)

**Reeves (2016)** · *Soapy documentation (Read the Docs)* · [Free full text](https://soapy.readthedocs.io/en/latest/simpleTutorial.html)

## Summary

The "Simple Tutorial" in the documentation of the Soapy Python AO simulation code guides a new user through running an example single-conjugate AO configuration, creating a new configuration file (simulation, atmosphere, telescope, WFS, DM and science parameters), running the simulation, examining the output data and changing parameters, and finally setting up a ground-layer AO example. It is a short practical entry point into end-to-end AO simulation; the code itself is listed in the simulation topic.

# COMPASS tutorials (GPU-based AO simulation platform)

**COMPASS team (2021)** · *COMPASS project website (Observatoire de Paris)* · [Free full text](https://compass.pages.obspm.fr/website/tutorials/)

## Summary

The COMPASS website hosts a series of tutorials (2021-2023) for its GPU-accelerated AO simulation platform, developed largely for ELT-scale studies. Topics include using the generic linear controller (state-space and IIR controllers written as generic recursions), modal gain optimisation with the CLOSE algorithm, custom deformable mirror definitions, and the coronagraph module. They assume an installed COMPASS environment (Linux with an NVIDIA GPU). The platform itself is described in the simulation topic.

# HCIPy tutorial notebooks (adaptive optics, wavefront sensing and coronagraphy)

**Por et al. (2018)** · *HCIPy documentation (GitHub, ehpor/hcipy)* · [Free full text](https://github.com/ehpor/hcipy/tree/master/doc/tutorial_notebooks)

## Summary

The HCIPy package documentation includes a set of executable Jupyter tutorial notebooks that double as an introduction to computational optics for AO and high-contrast imaging. Notebooks cover core concepts (grids, fields, wavefronts and optical elements), Fourier transforms and near/far-field diffraction, telescope pupils, broadband PSFs, atmospheric turbulence simulation, Shack-Hartmann and pyramid wavefront sensors, segmented deformable mirrors, the vector Zernike wavefront sensor, fibre coupling, vortex and vector-apodizing-phase-plate coronagraphs, and electric field conjugation. The software itself is described in the HCIPy paper listed in the simulation topic; the authors listed here are those of that paper.

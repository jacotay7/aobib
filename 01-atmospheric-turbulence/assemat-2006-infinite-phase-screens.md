# Method for simulating infinitely long and non stationary phase screens with optimized memory storage

**Assémat et al. (2006)** · *Optics Express 14, 988* · [Free full text](https://opg.optica.org/oe/fulltext.cfm?uri=oe-14-3-988) · DOI: [10.1364/OE.14.000988](https://doi.org/10.1364/OE.14.000988)

## Summary

Presents a method for generating arbitrarily long atmospheric phase screens by adding new rows (or columns) one at a time to an existing screen, each new row being drawn from the statistics of the turbulence conditioned on the preceding rows. Because only a small band of previous phase values must be stored, memory requirements are much lower than for generating a single large FFT screen. The approach also allows the turbulence statistics to change along the screen, producing non-stationary screens. The method is aimed at time-domain AO simulation in which screens are translated across the pupil under the frozen-flow assumption.

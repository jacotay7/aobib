# On-sky demonstration of matched filters for wavefront measurements using ELT-scale elongated laser guide stars

**Basden et al. (2017)** · *MNRAS 466, 5003* · [Free full text](https://arxiv.org/abs/1702.03736) · DOI: [10.1093/mnras/stx062](https://doi.org/10.1093/mnras/stx062)

## Summary

The paper demonstrates on sky a matched-filter algorithm for processing elongated laser guide star Shack-Hartmann spots, using the CANARY instrument on the 4.2 m William Herschel Telescope with the ESO Wendelstein LGS unit placed 40 m away to reproduce ELT-scale elongation. The matched filter, selected for the Thirty Meter Telescope but not previously demonstrated on sky, is described together with the methods used to implement it in the real-time system. Results from a first observing run show that matched filtering improves AO performance, with on-sky H-band Strehl increased by up to a factor of about 1.1 relative to a conventional centre-of-gravity approach.

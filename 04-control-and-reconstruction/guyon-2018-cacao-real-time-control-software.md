# The Compute and Control for Adaptive Optics (cacao) real-time control software package

**Guyon et al. (2018)** · *Proc. SPIE 10703, 107031E* · [Free full text](https://subarutelescope.org/staff/guyon/publications/2018/2018-06-11_SPIE/cacao/proceedings/cacao.pdf) · DOI: [10.1117/12.2314315](https://doi.org/10.1117/12.2314315)

## Summary

Describes cacao, an open-source, modular software environment for real-time control of adaptive optics systems that uses many-core CPU and GPU hardware to scale to high frame rates and high actuator counts. Its design is centred on data streams held in shared memory with a synchronization mechanism between computing processes, and users can add features through modules using this stream format. The paper describes the architecture and design approach and shows that accurate timing knowledge is key to several advanced operating modes. Current and future development priorities, including machine-learning support for real-time optimization, are discussed.

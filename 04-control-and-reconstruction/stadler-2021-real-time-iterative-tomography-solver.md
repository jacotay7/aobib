# Parallel implementation of an iterative solver for atmospheric tomography

**Stadler et al. (2021)** · *Proc. ICCSA 2021 (IEEE), 123* · [Free full text](https://arxiv.org/abs/2009.00946) · DOI: [10.1109/ICCSA54496.2021.00026](https://doi.org/10.1109/ICCSA54496.2021.00026)

## Summary

Focuses on performance optimization of the Finite Element Wavelet Hybrid Algorithm (FEWHA), an iterative wavelet-based solver for atmospheric tomography, as an alternative to matrix-vector multiplication for ELT-scale AO. Its matrix-free operator representation reduces floating-point operations and memory usage. The paper applies parallel programming models to implement FEWHA on CPUs and GPUs. The computational performance of the optimized parallel version is evaluated for ELT-sized test configurations.

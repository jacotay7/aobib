# Investigation of POWER8 processors for astronomical adaptive optics real-time control

**Basden (2015)** · *MNRAS 452, 1694* · [Free full text](https://arxiv.org/abs/1506.07927) · DOI: [10.1093/mnras/stv1396](https://doi.org/10.1093/mnras/stv1396)

## Summary

Investigates IBM POWER8 processors for ELT adaptive optics real-time control, a problem partly limited by the memory bandwidth needed for wavefront reconstruction. The large memory bandwidth of these processors is shown to make them suitable for first-light ELT instrumentation. Potential real-time control system designs are proposed. The author argues that a CPU-based system reduces complexity, improves maintainability and increases longevity.

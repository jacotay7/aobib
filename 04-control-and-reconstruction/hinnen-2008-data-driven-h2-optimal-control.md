# A data-driven H2-optimal control approach for adaptive optics

**Hinnen et al. (2008)** · *IEEE Trans. Control Syst. Technol. 16, 381* · [Free full text](https://repository.tudelft.nl/record/uuid:c8948513-da9c-4800-a45f-557dc61fa26d) · DOI: [10.1109/TCST.2007.903374](https://doi.org/10.1109/TCST.2007.903374)

## Summary

Presents a data-driven control design for adaptive optics that exploits the spatio-temporal correlation of the wavefront instead of the usual control law, which ignores how atmospheric distortions evolve, and without assuming the modes are decoupled. A dedicated subspace-identification algorithm builds an atmospheric disturbance model from open-loop wavefront-sensor data, and an H2-optimal controller is then designed from it. When the deformable mirror and wavefront sensor dynamics can be represented by a delay and a two-tap impulse response, the optimal controller has an analytical expression. Simulations using data from an AO test bench show a performance improvement over the common AO control approach.

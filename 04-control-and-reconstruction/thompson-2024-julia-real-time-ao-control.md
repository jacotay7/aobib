# Real-time adaptive optics control with a high level programming language

**Thompson et al. (2024)** · *Proc. SPIE 13097 (Adaptive Optics Systems IX)* · [Free full text](https://arxiv.org/abs/2407.07207) · DOI: [10.1117/12.3020480](https://doi.org/10.1117/12.3020480)

## Summary

Notes that AO systems are usually prototyped in a convenient but slow language such as MATLAB or Python and then rewritten in C/C++ for real-time control, duplicating effort. The paper presents a technical demonstration of real-time, sub-millisecond-latency control of an adaptive optics system written in the high-level Julia language. The open-source software supports multiple cameras, pixel streaming and network-transparent distributed computing, and can be interfaced with other programming languages.

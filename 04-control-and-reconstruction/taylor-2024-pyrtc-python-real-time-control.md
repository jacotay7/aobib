# pyRTC: open-source Python real-time control for adaptive optics

**Taylor (2024)** · *Open-source software (GitHub)* · [Free full text](https://github.com/jacotay7/pyRTC)

## Summary

pyRTC is an object-oriented Python package for adaptive optics real-time control, aimed at simulation-driven development, laboratory integration and controller research. Its components include wavefront sensors, slope processors, loop controllers, wavefront correctors and science cameras. These can run in a single-process development mode or in a multi-process mode communicating through shared-memory streams. The project documentation is hosted on Read the Docs, and the software is distributed under the GPL-3.0 licence.

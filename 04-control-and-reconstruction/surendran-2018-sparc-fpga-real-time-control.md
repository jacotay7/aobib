# Scalable platform for adaptive optics real-time control, part 1: concept, architecture, and validation

**Surendran et al. (2018)** · *JATIS 4, 039001* · [Free full text](https://arxiv.org/abs/1806.03073) · DOI: [10.1117/1.JATIS.4.3.039001](https://doi.org/10.1117/1.JATIS.4.3.039001)

## Summary

Demonstrates SPARC, an FPGA-based architecture for adaptive optics real-time control that exploits the configurable parallel processing of FPGAs, implemented on an inexpensive Xilinx VC-709 development board. SPARC is scalable across numbers of subapertures and pixels per subaperture and is intended as a generic real-time control kernel. For Shack-Hartmann sensors the total reconstruction time ranges from a median of 39.4 microseconds (11x11 subapertures) to 1.283 ms (50x50), with large-sensor latency dominated by DDR memory access on the development board. A companion Part 2 describes the FPGA implementation details.

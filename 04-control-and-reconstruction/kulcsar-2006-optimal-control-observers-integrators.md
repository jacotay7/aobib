# Optimal control, observers and integrators in adaptive optics

**Kulcsár et al. (2006)** · *Optics Express 14, 7464* · [Free full text](https://hal.science/hal-04511034) · DOI: [10.1364/OE.14.007464](https://doi.org/10.1364/OE.14.007464)

## Summary

Addresses residual phase variance minimization in adaptive optics loops from a control-engineering perspective. With a suitable state-space model, the problem separates into an optimal deterministic control problem and an optimal estimation problem, whose solutions are a linear quadratic controller and a Kalman filter. The framework is used to analyse existing AO controllers, which are shown to contain an implicit turbulent-phase model. In particular, standard integrator-based controllers implicitly assume a constant turbulent phase, which makes them prone to wind-up.

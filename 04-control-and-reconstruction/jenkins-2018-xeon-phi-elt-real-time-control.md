# ELT-scale adaptive optics real-time control with the Intel Xeon Phi Many Integrated Core Architecture

**Jenkins et al. (2018)** · *MNRAS 478, 3149* · [Free full text](https://arxiv.org/abs/1805.07254) · DOI: [10.1093/mnras/sty1310](https://doi.org/10.1093/mnras/sty1310)

## Summary

Proposes the Intel Xeon Phi Knights Landing many-integrated-core architecture for ELT-scale AO real-time control, whose computational demands scale with the fourth power of telescope diameter. The large number of low-power x86 cores and integrated high-bandwidth memory provide the parallelism and memory bandwidth needed for wavefront reconstruction. The Xeon Phi is shown to perform ELT-scale single-conjugate AO control computation at over 1.0 kHz with less than 20 microseconds RMS jitter, and to run the loop with a camera attached at up to 966 Hz, the camera's maximum frame rate. Use of Xeon Phi clusters for MCAO and MOAO is left for future work.

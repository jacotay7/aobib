# Efficient implementation of pseudo open-loop control for adaptive optics on Extremely Large Telescopes

**Basden et al. (2019)** · *MNRAS 486, 1774* · [Free full text](https://arxiv.org/abs/1903.12124) · DOI: [10.1093/mnras/stz918](https://doi.org/10.1093/mnras/stz918)

## Summary

Addresses the computational cost of pseudo-open-loop (POL) slope computation required by closed-loop systems using minimum mean square error reconstruction. POL slopes are the sum of measured residual slopes and the slopes reconstructed from the previous actuator demands, usually involving a dense interaction-matrix multiplication that requires high memory bandwidth on ELT-scale systems. The paper shows that this requirement can be significantly reduced while maintaining mathematical correctness. This lowers system complexity and cost and improves robustness.

# Solar image restoration by use of multi-frame blind de-convolution with multiple objects and phase diversity

**van Noort et al. (2005)** · *Solar Physics 228, 191* · [Free full text](https://www.researchgate.net/publication/226160889_Solar_Image_Restoration_By_Use_Of_Multi-frame_Blind_De-convolution_With_Multiple_Objects_And_Phase_Diversity) · DOI: [10.1007/s11207-005-5782-z](https://doi.org/10.1007/s11207-005-5782-z)

## Summary

Presents multi-object multi-frame blind deconvolution (MOMFBD), a post-processing method for restoring solar images taken with adaptive optics. It generalizes multi-frame blind deconvolution with phase diversity so that images of different objects, for example simultaneous exposures in several wavelengths or narrow-band filters, can be restored together with a common set of wavefront estimates. The paper describes the formalism and implementation and illustrates the method on data from the Swedish 1-m Solar Telescope. The method was implemented in C++ as an image-restoration server to which many worker clients can connect, so that restorations can be spread over many CPUs.

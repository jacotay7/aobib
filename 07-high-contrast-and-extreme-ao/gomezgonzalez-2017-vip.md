# VIP: Vortex Image Processing Package for High-contrast Direct Imaging

**Gomez Gonzalez et al. (2017)** · *AJ 154, 7* · [Free full text](https://arxiv.org/abs/1705.06184) · DOI: [10.3847/1538-3881/aa73d7](https://doi.org/10.3847/1538-3881/aa73d7)

## Summary

Presents VIP, an open-source Python library for high-contrast imaging data processing. The paper describes its capabilities for angular differential imaging sequences, including pre-processing, PSF subtraction with several PCA variants (annular and incremental PCA for large datacubes), source position and flux estimation, and sensitivity curves. It also introduces an ADI algorithm based on non-negative matrix factorization and demonstrates the package on LBTI/LMIRCam vortex coronagraph data of HR 8799.
